# i18n (placeholder)

externalised from components. The prototype hardcodes English — that is tracked tech debt.

This folder is reserved for the string-extraction layer (e.g. a lightweight `t()` +
locale JSON files, or a library like `i18next`). Not implemented yet — no business logic
in this scaffold phase.
